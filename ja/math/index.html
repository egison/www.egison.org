Egison 数学ノート

Notebookを手元で実行する

上の各ページは、egison-jupyterの ja/math/ディレクトリにある実行済みNotebookから生成しています。 Egison 5をインストールして カーネルのインストール手順を実行すると、手元のJupyterでも同じ計算を再実行できます。 

git clone https://github.com/egison/egison-jupyter.git
cd egison-jupyter
python3 -m venv .venv
source .venv/bin/activate
pip install . jupyter
python -m egison_kernel.install
jupyter notebook ja/math/
