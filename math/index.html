Egison Mathematics Notebook

Run the notebooks on your computer

Every page above is rendered from an executed notebook in the math/ directory of egison-jupyter. Install Egison 5 and follow the kernel installation guide, then start Jupyter in the repository. 

git clone https://github.com/egison/egison-jupyter.git
cd egison-jupyter
python3 -m venv .venv
source .venv/bin/activate
pip install . jupyter
python -m egison_kernel.install
jupyter notebook math/
